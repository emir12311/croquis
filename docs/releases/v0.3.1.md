Offline circuit simulator: build an Arduino circuit on a canvas, write a sketch, and run
it on a real AVR core. No server, no account, no network.

- **AppImage** — recommended. `croquis-0.3.1-x86_64.AppImage`
- **.deb** — `sudo apt install ./croquis_0.3.1_amd64.deb`
- **.rpm** — `sudo dnf install ./croquis-0.3.1-1.x86_64.rpm`
- **Arch, Artix, Endeavour** — `sudo pacman -U croquis-0.3.1-1-x86_64.pkg.tar.zst`

Every package carries its own AVR toolchain and the bundled Arduino libraries, so
compiling a sketch needs nothing else installed. AGPL-3.0.

## Fixed in 0.3.1

- **Touching pins conduct.** A part dragged so its pin landed on another pin looked
  connected and did nothing: the netlist joined only what a wire joined. Contact is a
  wire in its own right now, and it feeds the rail resolution as well as the net union —
  unioning the pins alone was not enough, because a circuit with no wires then has no
  rails to work out and stays dark.
- **A resistor reads as a number and a unit.** It was one drag box showing `10000 Ω`,
  with the catalogue's pΩ–TΩ table unused. It is `10` beside a `kΩ` dropdown, and the
  value still lands in the file as a plain ohm count.
- **A resistor's colour bands follow its value.** The element's drawing is a fixed 220 Ω,
  so every resistor looked like 220 Ω however it was set. 10 kΩ now draws brown, black,
  orange; 4k7 draws yellow, violet, red.
- **Clicking a dropdown item no longer deselects the part.** The canvas reads the pointer
  from raw input, so a click on the popup — which floats above the canvas but sits inside
  its rect — was read as a click on empty canvas, which cleared the selection and closed
  the properties strip mid-change.
- **The properties strip is one line.** The number box was pinned to 18 px while the
  dropdown sized itself from text plus padding, and each centred on its own box.

## Changed in 0.3.1

- **The v0.2 Tauri app is gone.** `src/`, `src-tauri/`, the npm toolchain and the two
  scripts that drove it are removed. Nothing had run their tests since v0.3 replaced the
  app, and carrying them meant carrying a second build nobody exercised.
- **The app lives in `app/`.** `spike/egui` was a spike's name on the only thing that
  ships; `git mv` kept the history with the files.
- **A new README**, reorganised around what people scan for, and a screenshot that shows
  the current app rather than v0.1.

Everything else is 0.3.0 — see [its notes](v0.3.0.md). 258 tests: 171 in the app, 62 in
the core, 25 in the simulator.
