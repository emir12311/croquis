Offline circuit simulator: build an Arduino circuit on a canvas, write a sketch, and run
it on a real AVR core. No server, no account, no network.

- **AppImage** — recommended. One file, no root, works on any distribution. Adds itself
  to your application menu on first launch.
- **.deb** — `sudo apt install ./Croquis_*.deb`
- **.rpm** — `sudo dnf install ./Croquis-*.rpm`
- **Arch, Artix, Endeavour** — `packaging/arch/PKGBUILD` in the source, `makepkg -si`

Every package carries its own AVR toolchain, so compiling a sketch needs nothing else
installed. AGPL-3.0.

## Fixed in 0.1.1

- **Presets frame themselves when loaded** — a circuit no longer opens half off-screen.
- **Compiles use a per-process build directory** — two instances, or two users on one
  machine, no longer overwrite each other's `sketch.elf`.
- **The from-source build is documented completely** — the instructions now include
  `scripts/build-toolchain-dist.sh`, the step that creates the toolchain the package
  bundles. A clean clone following the docs now builds.
- **Serial output no longer stutters** — it appends and trims only past the cap instead
  of rebuilding a 20,000-character string on every byte.
- **Two stale claims corrected** — `package.json` said `0.0.0`, and the breadboard notes
  said 9.6px when the grid is `67/7`px.
