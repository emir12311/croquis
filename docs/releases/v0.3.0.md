Offline circuit simulator: build an Arduino circuit on a canvas, write a sketch, and run
it on a real AVR core. No server, no account, no network.

- **AppImage** — recommended. One file, no root, works on any distribution.
  `croquis-0.3.0-x86_64.AppImage`
- **.deb** — `sudo apt install ./croquis_0.3.0_amd64.deb`
- **.rpm** — `sudo dnf install ./croquis-0.3.0-1.x86_64.rpm`
- **Arch, Artix, Endeavour** — `sudo pacman -U croquis-0.3.0-1-x86_64.pkg.tar.zst`

Every package carries its own AVR toolchain and the bundled Arduino libraries, so
compiling a sketch needs nothing else installed. AGPL-3.0.

## Rewritten in 0.3.0

The app is **Rust and egui** now, not Tauri, Svelte and a WebView. There is no Node, no
npm, and no embedded browser: the shell draws the circuit itself, and the same language
covers the engine and the UI. It builds with one `cargo build`.

## Added in 0.3.0

- **A language system.** English and Turkish, in **View → Language**, remembered between
  runs. Part and field names live in `assets/locales/*.json` and `croquis-core` carries
  keys rather than English, so a new part cannot ship without a translation.
- **Undo and redo** over the circuit, 64 steps deep. A drag is one step, not one per
  frame.
- **Wire colours** — the eight colours v0.2 offered, drawn as a halo so the chosen colour
  is never hidden by the selection. Right-click a wire to change it.
- **Wire corner editing done properly.** Corners are the wire's own, not the waypoints
  the router happened to store, so a wire that bends around a part gives you a corner to
  grab. Endpoints re-plug into other pins.
- **A v0.2-shaped context menu** — Copy, Cut, Duplicate, Rotate 90°, Rotate 180°,
  Delete, and Edit code on the Uno. Right-clicking also selects what is under the
  pointer, as v0.2 did.
- **A light theme** in **View → Light theme**, remembered between runs. It repaints the
  chrome only: part art and wire colours are the circuit's, not the theme's.
- **Switch bounce** in the **Run** menu — turn it on and a switch's contact chatters as
  it changes, so a sketch with no `debounce()` really does see several edges per press.
  Off by default, and read when the simulator starts.
- **A guard on unsaved work.** New, Open and closing the window ask **Save / Discard /
  Cancel** before replacing a circuit that has changed since it was saved.

## Changed in 0.3.0

- **Panels** are the sketch (left), the components (right) and the serial monitor
  (bottom). Each folds to its header with a chevron that points the way it will go.
- **Dragging** selects with a box on the left button; **right- or middle-drag pans**.
- **The editor** is `egui_code_editor`: syntax colouring, completion from the Arduino
  API, auto-indent, and long lines wrap. Line numbers are off — the widget cannot wrap
  and number at once, and a line cut off at the panel edge hides code while a missing
  gutter only hides a count.
- **The app opens on a blank canvas** with the `setup()` / `loop()` template, rather
  than loading the Blink example.
- **Packaging** builds one payload and wraps it four ways, so the packages cannot
  disagree about what is inside. The Arch package is a prebuilt download, because a
  source recipe could not ship the bundled toolchain.

## Fixed in 0.3.0

- **A wire grew a bend every time it was saved.** Pin positions are `f32`, route
  arithmetic is `f64`, and a decoded corner that sat six millionths off its neighbour's
  axis made the router insert an elbow, which the next save wrote out as a real bend.
  All 24 presets now survive a save → load → save round trip unchanged.
- **Saved positions crept.** They are quantised to four decimal places now, so opening
  and saving a circuit no longer nudges its parts.
- **Hit-testing follows draw order** — a pin hidden under another part is no longer
  pickable through it, and a wire over a part is picked, as it is drawn.
- **Ctrl+C / Ctrl+V / Ctrl+X work.** eframe turns them into events, and the clipboard
  feature was off, so the app had a stub clipboard that copied nothing.
- **The stepper no longer stalls the frame.** Its rotor was re-rasterised for every
  angle; it is drawn live now, like the potentiometer's tick.
- **New keeps the palette art** instead of re-rasterising all 31 parts each time.

### Known limits

- Clicking a compiler error does not move the caret: the editor widget exposes no way to
  place one, so diagnostics name their line but cannot be jumped to.
- One board. A second Uno gets its own circuit but shares the single sketch.
- It is a small series electrical model, not a circuit solver.

### Under the hood

- `crates/croquis-core` (netlist, diagram format, routing) and `crates/croquis-sim`
  (compile and simulate) are unchanged in role; the shell is the new part.
- Tests: 167 in the app, 61 in the core, 25 in the simulator. All 24 preset circuits are
  compiled and simulated by the suite, and checked against the frozen v0.2 baseline.
- `pr.yml` runs the app and engine suites on every pull request now; it used to run only
  the Tauri app's.
