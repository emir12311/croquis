Offline circuit simulator: build an Arduino circuit on a canvas, write a sketch, and run
it on a real AVR core. No server, no account, no network.

- **AppImage** — recommended. One file, no root, works on any distribution. Adds itself
  to your application menu on first launch.
- **.deb** — `sudo apt install ./Croquis_*.deb`
- **.rpm** — `sudo dnf install ./Croquis-*.rpm`
- **Arch, Artix, Endeavour** — `packaging/arch/PKGBUILD` in the source, `makepkg -si`

Every package carries its own AVR toolchain and bundled Arduino libraries, so compiling
a sketch needs nothing else installed. AGPL-3.0.

## Added in 0.2.0

- **The rest of the common starter kit.** RGB LEDs, slide potentiometers, photoresistor
  and NTC modules, an analog joystick, tilt, PIR, flame, gas and sound sensors, a DHT22,
  an HC-SR04, a 4×4 keypad, an IR receiver and remote, a 74HC595, a servo, a stepper,
  an LCD1602, a buzzer, a relay, 1- and 4-digit 7-segment displays, and an LED bar.
- **Offline libraries.** `Servo`, `LiquidCrystal`, `DHT`, `Keypad`, `Stepper` and
  `IRremote` are bundled with the app, so their sketches compile without installing
  anything.
- **Twenty-four starter circuits**, grouped under **File → Presets → Basics / Sensors /
  Outputs**: from Blink and Button through the sensors, displays, servo, stepper,
  keypad, LCD and shift register.
- **Buzzer audio** — a square tone at the driven pin's frequency, and 1 kHz for a steady
  high.
- **Relay contacts** switch `P1/P2` between `NC` and `NO`, so a relay can switch a real
  load, not just light a badge.
- **4-digit displays** retain every digit between multiplexed scans.
- **Serial input** — the monitor's input row feeds `Serial.read()` in the running sketch.
- **Clickable compiler errors** — each diagnostic jumps to its line in the editor.

## Fixed in 0.2.0

- **Snapping on a first-launch canvas** — a part dropped on a freshly placed breadboard
  now lands in its holes instead of off the board.
- **Canvas resizing** — opening the serial monitor or resizing the window no longer
  leaves the circuit drawn at the old size.
- **Preset wiring** — the 7-segment and 4-digit presets draw their wires, and the
  4-digit display updates when Run is pressed.
- **Buzzer drawing** — the body is drawn at its real size and its legs line up with the
  pins.
- **Serial follow and throughput** — the monitor follows new output unless you scroll
  up, and a chatty sketch no longer stutters the UI by flushing one byte at a time.
- **Preset menu clutter** — presets are collapsed behind a tabbed disclosure instead of
  filling the File menu.

### Under the hood

- Bundled-library objects live in their own cache directory and are linked with the
  sketch; the packages ship the `libraries/` tree alongside the toolchain.
- The pin meter distinguishes steady PWM from data traffic, so LCD nibbles and shift
  register clocks reach the UI while `analogWrite` still fades smoothly.
- WebKitGTK uses its accelerated renderer on Intel and AMD; the DMA-BUF fallback is kept
  for the NVIDIA proprietary driver and unidentified stacks.
- Remote controls and wireless parts dispatch their events to the element's own control
  rect, so they can be pressed on the canvas.
