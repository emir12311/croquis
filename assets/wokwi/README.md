# Wokwi element assets

Extracted from `@wokwi/elements` 1.9.2 by a one-off Vite/Chromium script that was removed along
with the v0.2 app. The files are checked in and no longer regenerated.

Each `<kind>.svg` is the element's default drawing, and `manifest.json` carries
the element box and `pinInfo` coordinates used by the native renderer. The two
breadboards and the 74HC595 are deliberately absent: Croquis draws those itself.

Do not edit these files by hand. Change the extractor or the catalogue and
regenerate. The artwork is MIT-licensed by Wokwi; see `LICENSE` in this folder
and the project `NOTICE`.
